Video Speed Presets Extension

Test page for your Chrome extension

📦 Installation Instructions

  1. Open Chrome and go to chrome://extensions/
  2. Enable "Developer mode" (toggle in top-right corner)
  3. Click "Load unpacked" button
  4. Select the folder containing the extension files (manifest.json, content.js, styles.css, icons)
  5. The extension is now installed!
  6. Refresh this page to see the speed controller appear in the top-left of the video
💡 How to use: Once installed and this page is refreshed, hover over the video to see the speed preset buttons (1.0x | 1.5x | 2.0x | 3.0x | 4.0x) in the top-left corner. Click any button to instantly change the playback speed!
